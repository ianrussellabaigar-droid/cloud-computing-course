# Cloud Computing Reflection

Cloud computing plays an important role in my daily life because I use many cloud-based applications such as Google Drive, Canva, and Facebook Messenger.

Google Drive is a Software as a Service (SaaS) application because it allows users to store and share files online. It uses the Public Cloud since it is accessible through the Internet.

Canva is also a SaaS application because it provides online graphic design tools without requiring software installation.

Facebook Messenger is another SaaS application that allows users to communicate through messages, voice calls, and video calls.

Git and GitHub are important because they help track changes, manage different versions of files, and allow teams to collaborate efficiently. Version control reduces errors and protects project history.

Learning GitHub has improved my understanding of cloud computing and collaboration. I believe these skills are valuable for my future career in Information Technology.
